# M14 validation — historical inspection and genealogy

Date: 2026-11-12. Status: **implemented; automated tests passed; walkthrough passed in Chromium (Playwright).** No state-schema, DB layout or frame-contract change (frame v9).

## Scope

| | |
|---|---|
| **No future data** (fix) | History views revealed the hidden lifespan of any organism that died *later* in the live run, while showing an earlier tick where it was still alive. Now `/api/history/{tick}` and `/api/organisms/{id}?at_tick=` reveal a lifespan only if the organism was dead **at that tick**. Already bounded by the selected tick and re-verified: events, decisions, memory (active and forgotten), messages, behaviour stats, interactions and the birth record. |
| **Key moments** | `GET /api/moments` lists the run's births (not seed births), deaths, accepted cell modifications and extinction, in sequence order. The *Recorded history* panel shows them with **before / after** buttons that seek to tick − 1 / tick, plus **◀ tick / tick ▶** stepping. |
| **Genealogy** | A *Genealogy* panel shows every organism that existed at the displayed tick as a parent→child tree (generation, born/died ticks, death cause). Clicking a node selects it. It follows history mode, so before a birth the child is absent. |
| **Causal navigation** | • **Event → decision:** an event's detail offers *open decision*, which selects the actor and opens that exact attempt in the Decision inspector.<br>• **Inherited memory → source:** *open source* seeks history to the birth tick, selects the parent and highlights the source record in its memory. |
| **Cell compared with now** | In history mode the cell inspector shows the live values, with deltas, beside the historical ones. |
| **Fixture** | `lineage` (dev, scripted):<br>• the parent extracts material, then packs 2 + 2 units into its cell (ticks 5–6, a lasting change);<br>• at tick 7 it gives birth east (endowment 30), passing two memories (a labelled 100% retention);<br>• the parent dies of age at tick 19; the child starves at tick 24, then extinction. |

Not added: editing the past, alternate histories, cross-run statistics, or an elaborate graph view.
