# M01 validation — canonical grid and browser inspector

Date: 2026-11-08. Status: **implemented; automated acceptance passed; real-browser visual acceptance pending the user's test**.

## Delivered scope

- Python domain owns an immutable 32 × 32 grid with 1,024 unique row-major cells.
- FastAPI serves the canonical frame, cell inspection, health and explicit new-run creation.
- React/TypeScript and Canvas 2D render the frame, select cells through pointer/keyboard/coordinate inputs, and display coordinates, index, run identity and checksum.
- SQLite stores each complete initial frame and the active-run reference transactionally. New runs retain previous records; refresh/restart restores the active run.
- Seed, UTC timestamp, version and source fingerprint establish minimal provenance. M01 seeds do not yet change cell contents.
- Failed API requests show a disconnected/waiting or explicitly stale-state view. Time progression remains disabled.

No organisms, resource behavior, inference adapters, model downloads, public hosting or M02 features were added. `AGENTS.md` retains SHA-256 `827d5eec86e377e39949402439056780e22114e9535c7ff63697f455bbf834aa`.

## Limits and next gate

Run archives are preserved in SQLite but do not yet have a history browser. The store is a minimal initial-state record, not the full event/replay system planned for M02/M03. The UI reads backend frames; presentation state never writes cell contents. All run configurations remain fixed at 32 × 32 in M01; seed is the only exposed creation parameter.

M02 remains unimplemented and awaits explicit approval after M01 review.
