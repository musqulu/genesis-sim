# UI-01 validation — visual stage, run setup bar, multi-organism live runs, run summaries

Date: 2026-11-09. Status: **implemented; automated tests passed; browser checks passed in Chromium (Playwright) with the real local model on an isolated stack — a human visual pass is still recommended**.

This is a requested interface and reporting change, not a roadmap milestone. It adds no new physics, actions, prompts, communication, transfer, reproduction or memory. `AGENTS.md` is unchanged.

## Delivered scope

- **Visual stage.**
  - The grid fills the page as a square canvas under a compact header (connection status, **Fullscreen**, **Dashboard**). The legend sits under the canvas.
  - **Fullscreen** uses the browser Fullscreen API on the stage; Esc leaves it.
- **Dashboard.** Every earlier panel is kept unchanged but hidden behind the **Dashboard** button: organisms, recorded history, cell inspector, run record and ledger, decision inspector, and event list. Nothing was deleted.
  - On wide screens (≥ 1100 px) it opens beside the grid; on narrower screens it opens as an overlay.
- **Hover details.** Hovering a living organism shows its id, its label, energy, carried material, age, position, and its last action with the model's explanation.
- **Control bar** (always visible under the grid). It holds the run controls (Start/Pause/Resume, Step, Speed, Pause at tick) and the new-run setup:
  - **Seed**;
  - **Model**: a dropdown of the discovered local models, or no organisms;
  - **Organisms** (1–12);
  - the test fixture selector, in dev mode only;
  - **New run** and **Summary** buttons.
- **Several organisms, one model.** All organisms in a run share one resident model worker, and each organism has its own request context. They are placed at distinct seeded cells, and the first placement is unchanged from before. The existing M06 barrier, rotation and queue were used with no engine change.
- **Run summaries** (`backend/genesis/ops/report.py`). These are plain-English Markdown built only from recorded data; no model writes them. Each summary covers:
  - each organism's lifespan, cause of death, and accepted and rejected decisions, with reasons in words;
  - what each organism did and its longest failed streak;
  - up to three quoted explanations, labelled as the model's words;
  - world changes, energy inflow and the ledger balance;
  - decision timing and tokens;
  - technical notes.

  Summaries are written:
  - automatically at extinction (the summary dialog also opens);
  - for the outgoing run when a new run replaces it;
  - on demand with **Summary**.

  The file is `data/reports/<date>_<run8>_seed<seed>.md`, or under `GENESIS_REPORTS_DIR` if that is set. A failure to write a report is only logged; it never affects the run.
- **API.**
  - `POST /api/runs` accepts `organisms`, which is valid only with a model.
  - New: `POST /api/summary` and `GET /api/summary`.
  - The frame contract is **v7** and adds `report_path`.

## Browser checks with the real model (`Qwen3.8-27B-Uncensored-MLX/8-bit`)

- The page opens on the grid alone, with no inspector panels until **Dashboard** is pressed.
- A 3-organism run (seed 7) started at three distinct cells:
  - all three organisms decided through **one** worker process;
  - the stage showed "3 of 3 alive";
  - the hover tooltip showed organism details.
- The run went extinct at tick 172 with no technical errors. The summary dialog opened by itself, and the `.md` file was saved.
  - The report showed 195 decisions, all valid JSON.
  - Two organisms died of old age at 100% of their hidden lifespan; one starved at tick 134.
  - Most rejections were requests for more than a cell held.
  - No cells were permanently changed, and the ledger balanced.
- Replacing an environment-only run at tick 3 wrote its summary ("stopped at tick 3 when a new run was started").
- Fullscreen puts the stage in fullscreen, and leaving it restores the page. At 420 px there is no horizontal scroll, and the grid and **New run** stay reachable.
- No page or console errors.

Regressions on the final build: M01/M02 full, M03, M04, M05, M06 and **M07 (22/22, real model, including the crash, resume and replay-without-model checks)** all passed. Script adaptations:
- open the Dashboard before inspecting panels;
- use the `Model` label;
- wait for the model list to load;
- close the summary dialog before starting a new run;
- leave fullscreen with `exitFullscreen()`, because headless Esc does not leave fullscreen.

## Known limits / unverified

- **Human visual check** of the new layout, tooltip and summary dialog is pending.
- **Memory with several runs:** each backend process loads its own model copy (~29 GB). A single run uses one copy for all its organisms.
- **Placement:** organisms are placed at random seeded cells, so some start on poor cells. That is a world condition, not something corrected.
